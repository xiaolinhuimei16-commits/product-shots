# Rakuten Image Plan Framework

A good product-image suite answers the shopper's questions in a deliberate order. This framework is adaptive, not a fixed checklist.

## Story sequence

Choose only the modules that fit the product.

| Stage | Possible image role | Shopper question |
|---|---|---|
| 1 | Hero / main selling message | What is this, and why should I stop? |
| 2 | Core experience / primary benefit | What will I experience or gain? |
| 3 | Main function / use demonstration | How does it work? |
| 4 | Feature close-up | What makes this product distinctive? |
| 5 | Texture / material / construction | What does it look and feel like? |
| 6 | Lifestyle scene 1 | Where and when would I use it? |
| 7 | Lifestyle scene 2 | Is there another relevant use situation? |
| 8 | Emotional appeal / delight | Why is it enjoyable or appealing? |
| 9 | Size / scale | How large is it in reality? |
| 10 | Variant overview | Which color, type, or SKU should I choose? |
| 11 | Package contents | What exactly will arrive? |
| 12 | How to use | How do I use it correctly? |
| 13 | Care / precautions | What should I know before use? |
| 14 | Comparison | What are the meaningful differences between options? |
| 15 | FAQ | What might stop me from purchasing? |
| 16-20 | Additional proof, use cases, giftability, seasonal context | Only when supported and genuinely useful |

## Motivation selection — do not force pain points

First decide which buying motivation is actually relevant:

- Problem-solving: removes friction or solves a concrete inconvenience.
- Sensory / decompression / play: tactile enjoyment, repetitive interaction, playful satisfaction, stress-relief positioning only when appropriate and not a medical claim.
- Emotional: comfort, delight, connection, reassurance.
- Aesthetic: appearance, styling, display, personalization.
- Practical: convenience, portability, storage, ease of use.
- Gift: recipient, occasion, presentation, gift readiness.
- Functional: clear feature or performance.
- Value / assortment: quantity, options, bundle contents.

One product may have one dominant motivation and several supporting motivations. Do not invent customer pain points just to fill a marketing template.

## Product-type adaptation example: sensory squeeze / squishy toy

Use only if the actual item and source photos confirm this product type. Possible storyboard logic:
1. Hero: make the primary squishy / squeeze item visually dominant; supporting SKUs are secondary.
2. Tactile experience: close-up of squeezing or pressing, with a clear deformation cue only if the real item deforms that way.
3. Texture / appearance: macro detail of the real surface and finish.
4. Rebound / recovery: show before-and-after only if the product truly returns to shape and the behavior is verified.
5. Multiple variants: show the real available variants, accurately mapped.
6. Use moments: desk break, study break, home relaxation, or travel only where realistic and safe.
7. Assortment / bundle: clearly distinguish single item from multi-piece set.
8. Dimensions: include only verified measurements.
9. Package contents: show exactly what is included.
10. Precautions: include only confirmed instructions.

Do not claim therapeutic effects, treatment of anxiety, guaranteed stress reduction, non-toxic status, child safety, or durability without appropriate evidence.

## SKU mapping table

Use the user's labels exactly. Numeric or alphabetic labels are both valid.

| User label | Actual variant / description | Source photo | Included quantity | Status |
|---|---|---|---|---|
| 1 / A | User-confirmed name | File/photo reference | Confirmed only | Confirmed / unknown |

If a SKU label or photo mapping is unclear, do not infer it.

## Image-count discipline

- Target 10-20 only when the product has enough distinct information.
- For a simple product, 6-10 excellent images can be better than 20 repetitive ones.
- Never repeat the same hero composition, scene, or headline merely to meet a count.
- Every image must answer a new question or provide new evidence.
