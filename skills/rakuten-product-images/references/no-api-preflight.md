# No-API Preflight

## What can be done without an image-generation API
- Catalogue supplied source images.
- Map photos to SKU labels (1/2/3 or A/B/C).
- Extract confirmed dimensions, materials, quantities, and packaging.
- Analyze purchase motivation and selling-point hierarchy.
- Produce a 10–20+ image storyboard.
- Write or proofread Japanese copy, preserving user-locked copy.
- Define Visual DNA: palette, typography, layout grid, spacing, lighting and scene direction.
- Produce layout specifications and static mockups from existing local assets.
- Prepare compositing instructions and QA reports.

## What cannot honestly be claimed without a renderer
- No new AI-generated lifestyle backgrounds.
- No model-generated image variations or image-to-image edits.
- No measured model-quality, latency, or per-image API-cost comparison.
- No completed end-to-end generation pipeline.

A local image model may avoid per-call API fees but requires compatible hardware, model downloads, setup, and electricity. Do not assume the user's GPU model or VRAM.

## Safe first test
1. Do not buy credits or enter payment details.
2. Run preflight and prepare the three-image pilot plan.
3. Use source images for a compositing/layout proof if a local editor or deterministic renderer is available.
4. Only when the user chooses generated backgrounds, compare providers on the same prompt and source asset.
5. Record total cost and revisions; stop if product fidelity fails.

Compare candidates using identical pilot briefs and source photos. Score product identity, background realism, texture, controllability, editability, and actual billed cost per accepted image. Exact Japanese should be typeset separately. Do not select a provider from marketing claims alone or recommend paid API before budget approval.
