# Rakuten Creative OS — 员工网页后台（本地 MVP）

这个目录已经是一个可运行的 **FastAPI + Pillow** 网页原型，不只是 Skill 文档。

## 运行步骤（Windows / macOS / Linux）

请使用 Python 3.10 或更新版本，在此仓库根目录执行：

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS / Linux:
# source .venv/bin/activate
pip install -r apps/rakuten-creative-os/requirements.txt
python -m uvicorn app:app --app-dir apps/rakuten-creative-os --host 127.0.0.1 --port 8765
```

打开 http://127.0.0.1:8765 ，开始员工使用流程：

1. 填写每个 SKU 的准确销售选项名称，上传对应真实照片（可选 A–M；只有上传的选项才参加排版）。
2. 上传**真正经老板认可**的视觉参考图。自定义基础色值；目前不自动模仿字体、精细装饰或完整排版。
3. 填写/检查12张日本文案标题。示例文案只是初稿，须由懂日语的负责人审核。没有证据的卖点不应写入。
4. 生成**仅用于内部检查**的12张联系表预览；不能用它作为交付的12张图。
5. 对SKU、文案、视觉参考和预览作人工审核确认。
6. 下载ZIP，内含 `01_Rakuten.jpg` 到 `12_Rakuten.jpg`，每张1000×1000px JPG，以及 `QA_MANIFEST.json`。

## 当前真实能力

- ✅ 浏览器上传真实商品照片
- ✅ SKU 与照片逐项对应；未提供照片的 SKU 不会被虚构出来
- ✅ 12张独立JPG的确定性排版与ZIP导出
- ✅ 本地工作、无自动上传到外部AI服务
- ✅ 可编辑日文标题与基本配色；审查门禁
- ✅ 不在商品照片内部画入 AI 生成的颜色、人物、材质或纹理

## 尚未实现、不要对员工夸大

- ❌ 不是你批准参考图的像素级复刻；模板需要设计师继续打磨
- ❌ 不是自动高级日语运营；人工日语审核必需
- ❌ 没有真实商品图自动识别/视觉一致性评分/水印检测
- ❌ 无多人账号、权限、团队数据库、操作日志、公司内网安全部署
- ❌ 不能自动完成Rakuten RMS上架，也不能保证自动满足全部最新平台要求
- ❌ 上传的原图若带中文、水印、难以分辨的细节，导出文件仍可能不适合正式上架
- ❌ 第11张若只上传部分SKU，只会展示那些已上传的选项；**不能把部分选项误当成全部完整SKU**
- ❌ PDF/PSD图层文件不是当前版的输入/交付格式

## 安全限制

只运行在 `127.0.0.1`，不要将无认证的网页应用使用 `0.0.0.0` 公开到互联网。上传数据仅在当前请求的内存中处理，没有数据库持久化；页面刷新后需要重新选择文件。不要把供应商未公开图片、密钥或私人客户资料提交到公开GitHub仓库。

## 自检命令

```bash
pip install httpx
python -m unittest discover -s apps/rakuten-creative-os -p 'test_*.py'
```

这套自动化 smoke tests 已写入仓库，但仍需在实际 Windows 员工电脑安装依赖、运行测试并检查中文/日文字体；如果日文显示方框，请安装 Noto Sans CJK 并通过 `RAKUTEN_FONT` 环境变量指定可用字体文件。首次接入真实商品前，仍须由负责人执行完整人工上架验收。
